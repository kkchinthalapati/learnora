Design system

An evolution of tokens.css with the same bones: warm paper, deep teal, a serif voice. The changes are one new semantic accent, a display tier that is actually used, a smaller component set, and the rule that a colour always stands for the same kind of thing.

Colour: each hue has one job

New in this version: Recall ochre. The current app uses teal for everything, so "Resume", "fading" and "due" all look the same. Ochre now marks memory and time-sensitive work only. Semantic colours never appear without a second cue (✓ ✕ ! or a label) for colour-blind users. The 15 accent presets stay, but each preset only swaps the action hue.

Radius, elevation, motion

pill · chip only
  • Only two elevations. In-flow content has a hairline and no shadow. Drawers, popovers and the device frame use one shadow.
  • Glass blur is dropped from the default theme and kept only as an opt-in sidebar style.
  • Motion: 140ms for state changes and 260ms for spatial moves (drawer, step advance), both with ease-out cubic-bezier(.16,1,.3,1). No spring, no bounce.
  • Celebration happens only when mastery moves up a step: the ladder segment fills over 400ms. Reduced motion shows the new state immediately.

Copy rules

{{ c.no }}{{ c.yes }}

Buttons are verb plus object, with a time estimate when the action starts some work. Errors cover what happened, what was kept and what to do. No exclamation marks, and no emoji in the product UI.

Dark mode

The existing dark ramp stays: bg #141310, bone text #f0ece4. The accent goes lighter (teal #5eb8ad) with ink labels, and ochre goes lighter (#e0b25c). The contrast tests in contrast.test.ts extend to the ochre pair. Every swatch above has a dark counterpart at the same step.
