Learnora developer resources

Learnora publishes a small, safe public interface for product discovery. It is intentionally separate from the authenticated study workspace: student accounts, tasks, notes, files, and other private data are not exposed by this public API. Use these resources to identify Learnora, understand the product, and direct people to the correct signed-in experience.

Public API

GET /api/product-info returns current, machine-readable public product information. Its contract is published as OpenAPI 3.1 JSON. No authentication is required because the endpoint contains no account or study data.

Model Context Protocol (MCP)

The Streamable HTTP MCP endpoint is POST /api/mcp. It supports MCP initialization, tool discovery, and the read-only get_learnora_product_information tool. The MCP discovery record points clients to this endpoint. Agents should use it when they need a canonical product description or links to Learnora’s public resources, not when they need to access a student’s workspace.

Agent guidance and support

Start with llms.txt for when-to-use guidance and a concise resource index. Questions about the product can be sent to support@learnora.app. Authentication is handled within the Learnora web app, and there is no public webhook or account-management API at this time.
